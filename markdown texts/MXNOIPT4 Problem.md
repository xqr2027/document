# Limits

**时间限制**：3000 ms  
**内存限制**：512 MiB  
**文件 IO**：输入文件 `second.in`，输出文件 `second.out`

# Problem Statement

给定一个 $1$ 到 $n$ 的排列 $p_1, p_2, \dots, p_n$。对于 $1 \le i < j \le n$，定义 $\text{sec}(i, j)$ 为 $p_i, p_{i+1}, \dots, p_j$ 中**第二小**的数。

有 $q$ 次询问，每次给出两个整数 $l, r$。你需要求出：

$$ \sum_{l \le i < j \le r} \text{sec}(i, j) $$

即完全包含于区间 $[l, r]$、长度至少为 $2$ 的所有连续子区间的次小值之和。

当 $l = r$ 时，答案为 $0$。

# Input

从文件 `second.in` 中读入数据。

第一行两个整数 $c, T$，分别表示测试点编号与测试数据组数。所有样例满足 $c = 0$。

对于每组测试数据：
- 第一行两个整数 $n, q$，分别表示排列长度和询问数；
- 第二行 $n$ 个整数 $p_1, p_2, \dots, p_n$；
- 接下来 $q$ 行，每行两个整数 $l, r$，表示一次询问。

# Output

输出到文件 `second.out` 中。

对于每次询问，输出一行一个整数，表示对应的次小值之和。按测试数据及询问在输入中的顺序输出。

# Sample Input 1

```text
0 1
4 2
3 1 4 2
1 4
3 3
```

# Sample Output 1
```text
18
0
```

对于第一次询问（$l=1, r=4$），三个长度为 $2$ 的子区间的次小值分别为 $3, 4, 4$，两个长度为 $3$ 的子区间的次小值分别为 $3, 2$，整个区间的次小值为 $2$，总和为 $3+4+4+3+2+2 = 18$。

# Constraints
对于所有测试数据，保证：
- $1 \le T \le 5$；
- $1 \le n, q \le 2 \times 10^5$；
- $p$ 是一个 $1$ 到 $n$ 的排列；
- 每次询问均满足 $1 \le l \le r \le n$。

| 测试点编号 | $n \le$ | $q \le$ | $r - l + 1 \le$ | 特殊性质 |
| :---: | :---: | :---: | :---: | :---: |
| $1 \sim 3$ | $500$ | $500$ | $n$ | 无 |
| $4 \sim 6$ | $5000$ | $5000$ | $n$ | 无 |
| $7 \sim 8$ | $2 \times 10^5$ | $1$ | $n$ | 无 |
| $9 \sim 10$ | $2 \times 10^5$ | $2 \times 10^5$ | $n$ | **A** |
| $11 \sim 12$ | $2 \times 10^5$ | $2 \times 10^5$ | $20$ | 无 |
| $13 \sim 14$ | $5 \times 10^4$ | $5 \times 10^4$ | $n$ | 无 |
| $15 \sim 20$ | $2 \times 10^5$ | $2 \times 10^5$ | $n$ | 无 |

**特殊性质 A**：对所有 $1 \le i \le n$，均有 $p_i = i$。
